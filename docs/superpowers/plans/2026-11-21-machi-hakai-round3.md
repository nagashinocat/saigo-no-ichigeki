# 街破壊 第3弾の直し 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.

**Goal:** 設計書 14章の直し。
**Spec:** `docs/superpowers/specs/2026-11-20-machi-hakai-design.md`（14章）

## Global Constraints
- 縦画面（390×844）が主。中くらいのAndroidで30fpsを目標に、重さを増やしすぎない。
- 画面の文言は日本語。見た目・音はすべてオリジナル。
- 既存のテストを弱めない。持ち主が選んだ釣り合い（「ギリギリのスリル」: 最善の操作で満タンが最後の数秒）は大きく崩さない。崩れる場合は数値で示す。

---

### Task H1: 音が途切れる原因を調べて直す
- systematic-debugging の進め方で、原因を突き止めてから直す。疑い: 小爆発（払う）が 'shot' を出して BGM の stop や releaseSilence を呼んでいる／新しく入れたリミッター（DynamicsCompressor）のかけ方／声の数の上限や onended の disconnect の早すぎ／suspend・resume／演出の無音の合図が遊んでいる間に漏れている。
- 遊んでいる60秒の間（長押し・払う・掴まれる・軍勢が多い）に BGM と効果音が途切れないことを、オフラインの再現かヘッドレスの記録（AudioContext の状態、各バスの gain の時刻ごとの値、BGM の状態）で示すテストを足す。

### Task H2: 爆発音をリアルに寄せる
- 合成のまま、実際の爆発に近い音にする: 最初の衝撃（短く鋭い、広帯域）、続く低いうなりと地響き（超低域の揺れ、ゆっくり減衰）、空気を裂く中域のノイズ、遠くから遅れて届く反射音（短い残響・遅延）、崩れる破片のぱらぱら。大きさで長さ・低さ・遅れを変える。小爆発（払う）は短く近い音、最後の一発は演出の時刻表の「弾ける」に合わせる。
- リミッターで割れないこと。試聴用 WAV（払う、最後の一発）を書き出す。

### Task H3: 軍勢は道路を飛んで探し回り、見つけたら捕まえに来る
- 状態: 探す（search）→ 見つけた（chase）→ 掴む（grab）→ 倒れる（dead）。探す間は道路の格子（26m 間隔の街区の間の道）に沿って速く飛び、交差点で曲がる。主人公から一定の距離の内側で、建物にさえぎられずに見えたら（または一定確率で）見つけた状態になり、主人公へ一直線に近づく。
- 速度を上げる（探す: 目安 14〜18 m/s、近づく: 8〜10 m/s、最後の数mで減速して横に止まる）。近くまで来たときに一瞬離れる動き（掴む位置の輪や順番待ちの輪へ移るときの戻り）をなくし、連続した動きにする。
- 判定（払う・爆発・掴む）は今のまま水平の距離で。ビルの陰の影絵と目印、目の一拍は働くこと。持ち主の釣り合いを大きく崩さない（届くまでの時間の分布をテストで示し、必要なら湧く数・見つける距離で合わせる）。

### Task H4: 最後の一発の広がりをゆっくり、見せ場のタイミングを作る
- 最後の一発の前線の曲線を、じわじわ期と弾ける期の後に「見せる」区間ができるよう遅くする（全体で目安 1.5〜2 倍の長さ。弾けたあと、ビルが飲まれていく様子・球の全体・宇宙での半球がゆっくり見られる）。小爆発は変えない。
- 演出（finaleTimeline / finalePlan / cinematic）とリプレイの時刻表、追うカメラ、宇宙のカット、BGM と効果音の合図をすべて新しい曲線に合わせる（finaleGameSync のテストは通すこと）。演出全体の長さは長くなりすぎないよう、見せ場以外を詰める。
